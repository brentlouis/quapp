# Civic Paper visual artifacts

This folder contains the downloadable visual reference exported from the original Claude artifact.

- `quapp-civic-paper.html` — single-file offline gallery.
- `quapp-civic-paper.zip` — downloadable archive.
- `quapp-civic-paper/` — 64 artboard HTML files, fonts, manifest, and notes, including the subsequent queue-card updates.
- `quapp-gallery-template.html` — editable gallery wrapper source.
- `quapp-preview.png` — quick preview image.

These artifacts document visual intent. They are not the Android app, do not contain a working backend, and do not prove a screen is implemented or device-tested.

Edit the artboards and notes in `quapp-civic-paper/`, then rebuild the downloadable gallery and ZIP with `../tools/rebuild-gallery.ps1`. The preview image may represent an earlier export.
