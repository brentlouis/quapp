# Android application

- `src/main/java/com/example/quapp/`: Java screens, adapters, models, and shared helpers.
- `src/main/res/`: XML layouts, styles, strings, icons, and textures.
- `src/main/AndroidManifest.xml`: application and Activity registration.
- `src/test/`: local unit tests.
- `src/androidTest/`: device test sources.
- `build.gradle`: application build settings and dependencies.
- `build/`: generated output; do not edit it as source.

Use the [repository map](../docs/repo-map.md) to locate a feature and the [debugging guide](../docs/debugging.md) to investigate it.
